# Sahara Apex Design

Build a world-class premium website for "Sahara Multi Fitness", a luxury gym and fitness center in Gangavathi, Karnataka. The website must feel like a ₹5 lakh agency-built product with cinematic animations, modern UI/UX, and flawless responsiveness across mobile, tablet, and desktop.

Use Next.js, TypeScript, Tailwind CSS, Framer Motion, GSAP, and Shadcn UI.
